# Superstore Sales Analysis

## Description
Excel-based analysis of a 9800-row retail dataset covering sales, profit, and customer data across multiple categories and regions.

## Tools Used
Microsoft Excel

## Skills Demonstrated
- Data cleaning and formatting
- VLOOKUP, XLOOKUP
- SUMIF, COUNTIF, AVERAGEIF
- Nested IF formulas
- Pivot Tables
- Charts and data visualization
- Conditional formatting
- Sorting and filtering

  ## Analysis Insights
- Analyzed 9,801 transactions from 2015 to 2018 with total revenue of $2,261,536
- West region was the top performer at $710,219. South was the weakest at $389,151, underperforming West by almost 50%
- Technology was the strongest product category overall
- East region led in Technology sales, slightly outperforming West in that specific category
- Central region performed consistently across all categories with no standout area
- Recommendation: Investigate why South region is underperforming, double down on Technology in the East region as it shows strongest growth potential

## Purpose
Completed as part of a structured Excel curriculum to develop proficiency in real-world data analysis using advanced Excel functions.
